# 生音（ShengYin）

这是一个微信原生小程序（wxml + wxss + js + json），用于记录每天让人印象深刻的声音和画面。所有数据使用 `wx.setStorageSync` 本地存储，适合作为前端演示项目直接在微信开发者工具中运行。

## 目录结构

- `app.js`：应用启动与示例数据初始化
- `app.json`：全局配置与页面注册
- `app.wxss`：全局样式
- `pages/index/index.*`：首页日历页
- `pages/day/day.*`：某天记录详情页
- `sitemap.json`：小程序站点地图

## 功能

- 本月日历首页，按天展示简单 emoji
- 每天可添加“此刻的声音”或“此刻的画面”
- 录音/拍照后写入当天记录
- 本地缓存，不丢失
- 可删除当天记录
- 可下拉刷新
- 纯前端演示，无后端依赖

## 如何运行

1. 打开微信开发者工具
2. 选择“导入项目”
3. 选择这个仓库目录
4. 确认项目类型为“小程序”
5. 点击“编译”，即可运行

> 备注：录音功能需要真机测试，模拟器/浏览器环境下可能无法正常录音。拍照也建议在真机环境体验更稳定。
